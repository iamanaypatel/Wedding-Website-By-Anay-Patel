# 💍 Wedding Website By Anay Patel

An elegant, modern, and fully-responsive wedding celebration website crafted with meticulous detail. Features a warm neutral aesthetic, live countdown, interactive RSVP management, event schedule, photo gallery with lightbox, venue details with interactive maps, travel recommendations, and wedding FAQs.

## ✨ Features

- **Hero & Live Countdown**: Real-time countdown timer to the wedding celebration with animated elements.
- **Love Story Timeline**: Elegant milestone timeline highlighting the couple's journey.
- **Wedding Schedule & Itinerary**: Multi-event itinerary (Welcome Drinks, Ceremony & Reception, Farewell Brunch).
- **Interactive RSVP System**: Complete RSVP form with acceptance status, dietary requirements, guest count, and song requests, including live confirmation.
- **Photo Gallery & Lightbox**: High-resolution gallery grid with click-to-expand lightbox view and captions.
- **Accommodations & Travel**: Curated stay recommendations, room block details, and transit info.
- **Registry & FAQ**: Gift registry links and collapsible accordion for common guest questions.
- **Mobile-First & Responsive**: Built with Tailwind CSS and responsive typography for mobile, tablet, and desktop.

## 🚀 Live Demo & Deployment

This project is a standalone single-page application (`index.html`).

### Enabling GitHub Pages
1. In your GitHub repository, navigate to **Settings** > **Pages**.
2. Under **Build and deployment** > **Branch**, select `main` and folder `/ (root)`.
3. Click **Save**.
4. Your website will be published and accessible at:
   `https://iamanaypatel.github.io/Wedding-Website-By-Anay-Patel/`
